# Zufallsgenerator

Ein schöner Zufallsgenerator für Zahlen und Namen. Er läuft vollständig lokal im Browser und benötigt keine Installation.

## Funktionen

- Zufällige ganze Zahl zwischen „Von“ und „Bis“
- Zufälliger Name aus einer eingegebenen Liste
- Verlauf der letzten fünf Ergebnisse
- Mobilfreundliches Design

## Starten

`index.html` im Browser öffnen.
